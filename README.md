# Cauri

Ventes, stock et carnet de crédits pour le petit commerce. Sans internet,
sans compte, sans serveur.

- **Essayer dans le navigateur** : https://johnibgg.github.io/cauri/app/
- **Télécharger pour Android** : https://johnibgg.github.io/cauri/Cauri-1.0.0.apk

Ce dépôt ne contient que le site publié : la page de vente, l'application
compilée pour le navigateur, et les fichiers d'installation Android.
Le code source n'y est pas.
