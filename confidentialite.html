Cauri

Confidentialité

Ce document tient en une phrase : Cauri ne collecte rien, parce qu’il en est techniquement incapable.

Ce que nous collectons

Rien. Aucune donnée personnelle, aucune donnée d’usage, aucune donnée commerciale ne quitte votre téléphone. Il n’y a pas de compte à créer, pas d’adresse e-mail à donner, pas de numéro à confirmer.

Ce n’est pas un engagement sur l’honneur. C’est une contrainte inscrite dans le fichier d’installation : l’application ne demande pas la permission d’accéder à internet. Android lui interdit donc d’ouvrir la moindre connexion réseau. Même si elle voulait envoyer vos chiffres quelque part, le système le lui refuserait.

Vous pouvez le vérifier vous-même, sans nous croire sur parole, avec n’importe quel analyseur d’APK :

aapt2 dump permissions Cauri.apk

La seule ligne qui apparaît est une permission interne d’Android, de niveau signature, qui ne donne accès à rien d’extérieur.

Où vivent vos données

Vos produits, vos ventes, vos clients, vos crédits et vos dépenses sont enregistrés dans un fichier de base de données, à l’intérieur de l’espace privé que le système réserve à l’application, sur votre téléphone. Aucune autre application ne peut le lire. Nous non plus.

Si vous désinstallez Cauri, ce fichier est effacé avec elle. Faites une sauvegarde avant.

La sauvegarde

Depuis la version 1.1, Cauri écrit chaque jour une copie de vos données, toute seule, au démarrage. Cette copie reste dans l’espace privé de l’application, sur votre téléphone : elle ne part nulle part et personne d’autre ne peut la lire. Les sept dernières sont conservées, les plus anciennes sont effacées.

Cette copie automatique vous protège d’une fausse manœuvre, pas d’un téléphone perdu : elle disparaît avec l’application si vous la désinstallez. C’est pourquoi Cauri vous rappelle chaque semaine d’en envoyer une hors du téléphone.

La fonction de sauvegarde écrit un fichier et vous le remet. C’est vous qui décidez où il va : WhatsApp, une carte mémoire, un courriel, un ordinateur. Il ne part vers aucun serveur, et il n’en existe aucune copie chez nous.

Ce fichier n’est pas chiffré : il se lit avec un éditeur de texte. Traitez-le comme vous traiteriez votre cahier — ne le laissez pas traîner.

Les données de vos clients

Quand vous inscrivez le nom et le numéro d’un client dans le carnet de crédits, ces informations restent sur votre téléphone, exactement comme les vôtres. Nous n’y avons pas accès.

Vous en êtes le responsable : c’est votre carnet, sous votre garde, avec les obligations que cela implique dans votre pays. Cauri vous donne de quoi supprimer une fiche client à tout moment, et de quoi tout effacer d’un coup depuis les Réglages.

Ce qui sort de l’application, et seulement si vous le demandez

Trois actions passent la main à une autre application de votre téléphone. Chacune part d’un geste de votre part, et vous voyez le message avant qu’il ne parte :

  • Partager un reçu — ouvre le partage du système. C’est vous qui choisissez le destinataire.
  • Relancer un client — ouvre WhatsApp avec un message déjà écrit. Vous le relisez, et c’est vous qui appuyez sur envoyer.
  • Passer en Pro — ouvre WhatsApp vers notre numéro, avec votre code appareil. Ce code est une suite de dix lettres tirée au hasard : il ne contient ni votre nom, ni votre numéro, ni aucune information sur votre téléphone.

Une fois la main passée, c’est la politique de confidentialité de l’autre application qui s’applique — celle de WhatsApp, par exemple. Nous n’y pouvons rien.

La version qui tourne dans le navigateur

La démonstration en ligne fonctionne de la même façon : tout est enregistré dans votre navigateur, sur votre appareil. Elle est remplie d’une boutique fictive, pour que vous puissiez essayer sans rien saisir. Rien n’est transmis à un serveur.

Le site est hébergé par GitHub Pages, qui enregistre les requêtes reçues comme le fait tout hébergeur. Nous ne consultons pas ces journaux et n’y avons pas ajouté de traceur : il n’y a ni cookie, ni mesure d’audience, ni régie publicitaire sur ces pages.

Les enfants

Cauri est un outil de travail destiné aux commerçants. Il ne s’adresse pas aux enfants et ne leur demande rien — puisqu’il ne demande rien à personne.

Si ce document change

Le jour où une version de Cauri accéderait au réseau — pour une sauvegarde en ligne, par exemple — ce serait écrit ici avant, et la permission internet apparaîtrait dans le fichier d’installation. Vous le verriez au moment de la mise à jour. Tant que cette permission est absente, la promesse ci-dessus tient toute seule.
