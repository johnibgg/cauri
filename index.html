Ce qu’on peut vérifier

Elle n’a pas le droit d’aller sur internet.

Ce n’est pas une promesse commerciale, c’est une ligne absente du fichier d’installation. Sans la permission INTERNET, Android empêche l’application d’ouvrir la moindre connexion. Elle ne peut pas envoyer vos chiffres ailleurs, même si elle le voulait. N’importe quel analyseur d’APK vous le confirmera.

Questions

Ce qu’on nous demande d’abord.

Ça va manger mon forfait ?

Non. L’application n’a pas l’autorisation d’accéder à internet. Mettez le téléphone en mode avion et vendez toute la journée.

Et si je perds mon téléphone ?

La sauvegarde est gratuite, avec ou sans abonnement. L’application écrit une copie chaque jour, et vous rappelle chaque semaine de vous l’envoyer sur WhatsApp. Sur le nouveau téléphone, vous rechargez ce fichier et tout revient — les créances, le stock, l’historique.

Comment je paie, sans carte bancaire ?

Mobile money, espèces, ou carte si vous en avez une. Vous donnez le code appareil affiché dans l’application, on vous renvoie un code d’activation de 16 caractères. Vous le saisissez — et ça marche même sans réseau.

Mon téléphone est vieux.

Android 5 suffit, et le fichier pèse 17 Mo. C’est justement pour ces téléphones-là qu’elle a été écrite.
